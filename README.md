# Tic-Tac-Toe Game

A working Python Flask Tic-Tac-Toe web application.

## Features
- Player vs Computer
- Easy difficulty
- Medium difficulty
- Winner detection
- Draw detection
- Score tracking
- New Game
- Reset Score
- Responsive web interface

## Requirements
- Python 3
- Flask

## Run the project

1. Open a terminal in this project folder.
2. Install Flask:

   pip install flask

3. Start the application:

   python app.py

4. Open this address in your browser:

   http://127.0.0.1:5000
